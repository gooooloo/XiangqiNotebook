用皮卡鱼（Pikafish）引擎分析 XiangqiNotebook app 当前局面里的着法好坏，并用地道中文讲清原因。

## 前置条件

- XiangqiNotebook（macOS 版）正在运行，`xiangqi-notebook` MCP 已连接。
- 用到三个 MCP 工具：`get_position`（读当前局面）、`evaluate`（引擎评估）、`apply_moves`（沿着法走子）。
- 若 `evaluate` 返回 409，说明引擎正忙——稍等再试，不要连续猛发。

## 分析流程

### 1. 读当前局面

先调用 `get_position`。重点看：`fen`（局面，「棋盘 r|b」，r/b 指谁走）、`nextMoves`（笔记本里已记录的后续着法，中文）、`variants`（本步变着）、`score`（云库分）、`engineScore`（已有引擎分）、`comment`/`moveComment`（用户笔记）。这一步同时告诉你现在轮谁走，以及待评点的着法是不是就是笔记本里那步。

### 2. 引擎评估当前局面

调用 `evaluate`，建议 `multipv: 5`、`movetime_ms: 12000`（要更硬的结论就 15000+；随手看看可以更短）。省略 `fen` 就是分析当前局面。

读结果：`lines` 按 `rank` 排好，每条有 `scoreCp`、`depth`、`pvUci`、`pvChinese`。关键点：

- **`scoreCp` 是走子方视角的厘兵分**，正数=走子方占优，100 ≈ 一个兵。杀棋折算到 ±30000 附近。
- 排在 rank 1 的就是引擎首选。把首选和用户问的那步做对比。

### 3. 若要评点某一具体着法

比如用户问「为什么车二进五不好」：

1. **先看它在不在候选排行里。** 如果一步棋连引擎前五名都进不去，本身就是它不好的强信号。
2. **把这步走出来看后果。** 用 `apply_moves`，`fen` 传第 1 步拿到的当前局面，`moves` 传该着法的 UCI，得到走完后的新 `fen`。
   - Chinese→UCI 坐标系：列 a–i 从**红方左侧**起，行 0–9 从**红方底线**起（如 `h2e2` = 炮二平五）。红方路数从右到左数一~九，即 i 列=一路 … a 列=九路。拿不准就先小样本核对。
3. **对新局面再 `evaluate`。**
4. **注意视角翻转。** 走完一步后轮**对方**走，新局面 `evaluate` 的 `scoreCp` 是对方视角。要换算到同一方再比。
   - 例：红方走子前引擎首选 +226（红优）；走完某步后轮黑，黑方最佳 ≈ 0——说明红方优势从 +226 掉到了 0，一步走没了两个多兵的便宜。
5. **务必算到对方的最佳应手，别只看一层。** 一步棋好不好取决于对方怎么接。读候选线路时不光看自己这步，还要看 PV 里**对方的回应**；或对走完后的新局面再 `evaluate`，读它 rank 1 那步——那就是对方的最强防守／反击。尤其警惕两点：
   - **对方的"中间手"（先手、腾挪、救子）。** 你这步若威胁不够硬，对方未必应你，反而能先走一手救回本该被你吃的子、或抢到先手，你白亏一步。判断一步"打某子／做某杀"的棋之前，先确认它**是不是真的逼对方非应不可**。
   - **用户给的着法顺序里逐手核对轮谁走。** 用户描述计划时常省略对方的应手；一个跳过了对方中间手的计划，往往正好慢一手。
6. **攻杀／弃子／沉底这类构想，一定要算到"能不能被化解"。** 别只验证"对方若配合就成杀"，必须走出**对方的最佳防守**再 `evaluate`：底线杀（如炮碾丹砂）常被升帅（帅／将Ｘ进一，老将离开底线就无处施力）化解，闷杀常被垫子解，抽将常被兑子挡回。攻势若能被一步解掉、自己却为此放弃了实惠（比如白得的子），那多半是坏棋。这类结论必须落到"对方最强防守下的引擎评分"，不能停在"我这套杀法看着很凶"。

### 4. 判断好坏的依据

综合这几条下结论，别只看单一数字：

- 这步在不在引擎候选前列（根本不在前五 = 明显非最佳）。
- 评估分变化多大（掉了多少厘兵，≈ 多少个兵的价值）。
- 对比正确走法，它少保住／少扩大了多少优势。

### 5. 讲解（本 skill 的重点）

引擎数字只是证据，用户真正要的是**为什么**。讲解时：

- **先给结论**（这步好／坏、大致亏多少），用引擎分对比支撑。
- **再讲道理**：从战略/战术层面给出直觉化的解释——它慢在哪、偏在哪、漏算了什么、让对方得到了什么先手或反击。让棋理自洽，不要堆一串坐标和分数了事。
- **给出正确应对**：引擎首选是什么，好在哪。
- 若用户要**粘贴到 app 注释**，另附一段纯文字精简版（几行连贯的话，不用表格和 markdown 标记）。

## 象棋术语规范（务必遵守）

用户明确、反复强调过这几条，讲解和注释里都要照做，否则读起来不地道：

- **描述棋子**用「路数＋兵种」：八路炮、四路马、五路炮、二路车……**不要**用「炮八」「马四」这种简写指代棋子，**更不要**用国际象棋坐标（b6、c5、h5）。
- **记谱**（一步棋的名字）用标准中文着法照写即可：炮八平七、马四进五、车9平6、炮4进5——这些是着法记录，不受上一条限制。
- **描述位置/形势**用象棋话，不用坐标：沉入黑方腹地、过河小卒、右翼边线、沉底炮、骑河车、卒林线……
- **攻击目标**说九宫、老将、中防、士角、象眼等；**不要**用「王城」这类非象棋词。

**对照示例：**

| 别这么写（坐标/简写/生硬） | 要这么写（地道） |
|---|---|
| 红炮在 b6，车走到 h5 攻 c5 的卒 | 八路炮已沉入黑方腹地，车开到右翼边线遥指一个过河小卒 |
| 炮八配合马四、炮五攻王城 | 八路炮配合四路马、五路炮直捣黑方九宫 |
| 评估从 +226 掉到 0 | 局面由红方胜势跌回均势，一步走掉两个多兵的便宜 |

## 一个完整例子（供参考语气与结构）

用户问「为什么车二进五不好」，分析后可以这样讲：

> 车二进五是一步价值两个多兵的失着，一手把胜势下成和棋。走这步前红方约 +226（已成胜势），走完之后黑方即可走成均势；引擎候选前五名里根本没有车二进五，首选是炮八平七。
>
> 红方本钱全在中路、直冲黑方九宫这一侧：八路炮已沉入黑方腹地，是把攻击尖刀；四路马与五路炮又构成中路突击的火力。正确思路是炮八平七后接马四进五、炮五进四，弃子轰开黑方中防。而车二进五把车开到右翼边线，只遥指一个过河小卒，目标又小又偏，还白送黑方车9平6整理阵型的一手先手，优势随即烟消云散。
